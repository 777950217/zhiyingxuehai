### P0-1：AI诊断API无超时控制

**问题描述**：`/api/ai/diagnose/route.ts`的`client.stream()`调用没有超时控制，如果LLM响应慢或卡住，请求会一直挂起。

**修复状态**：✅ **已修复**

**修复代码位置**：`src/app/(main)/api/ai/diagnose/route.ts` 第1377-1415行

**修复方案**：
- 添加15秒超时控制（`LLM_TIMEOUT_MS = 15000`）
- 使用`Promise.race()`包装LLM stream循环
- 超时后向客户端返回错误`"AI响应超时，请稍后重试"`并关闭SSE流
- catch块区分超时错误（`LLM_TIMEOUT`）和其他错误

**验证结果**：
- [x] 代码已修改并提交（commit `1ca540f`）
- [x] TypeScript编译检查通过
- [x] pnpm build构建成功
- [ ] 未实际测试15秒超时场景（需要Mock LLM延迟）

**结论**：代码级修复已完成，待集成测试验证。

### P0-2：Admin API无权限守卫

**问题描述**：`/api/admin/route.ts`的GET/POST方法没有权限检查，任何人都可以访问Admin API。

**修复状态**：✅ **已修复**

**修复代码位置**：`src/app/(main)/api/admin/route.ts` 第7-14行

**修复方案**：
- 添加`authenticateRequest(request)`权限检查
- 未登录返回401（`unauthorizedResponse('Admin API需要登录')`）
- 非admin角色返回403（`forbiddenResponse('仅管理员可访问此API')`）

**验证结果**：
- [x] 代码已修改（前次会话提交）
- [x] GET/POST方法开头都有权限检查
- [x] 使用了正确的认证工具函数（`authenticateRequest/unauthorizedResponse/forbiddenResponse`）

**结论**：代码级修复已完成，Admin API已有权限守卫。
