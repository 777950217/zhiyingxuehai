## 八、风险清单

### 高风险（需立即处理）

1. ❌ **Coze API key可能失效**（影响AI诊断功能）
   - 风险：AI诊断功能无法使用
   - 应对：上线前验证Coze API key有效性

2. ❌ **Supabase数据库连接失败**（影响所有DB功能）
   - 风险：KPI/话术/课程数据无法加载
   - 应对：上线前验证Supabase项目状态（是否暂停/删除）

### 中风险（需监控）

3. ⚠️ **LLM响应超时**（AI诊断可能超时）
   - 风险：用户体验差（转圈15秒后报错）
   - 应对：监控API错误率，必要时增加超时时间或优化prompt

4. ⚠️ **数据库性能瓶颈**（大量用户同时访问）
   - 风险：API响应变慢
   - 应对：监控数据库性能，必要时升级Supabase计划
